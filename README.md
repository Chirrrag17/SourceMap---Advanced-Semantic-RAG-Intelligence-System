## 🚀 What is SourceMap?

SourceMap helps developers **find and understand code instantly** using AI-powered semantic search. Instead of manually searching through 15,000+ lines of code, just ask:

- *"Show me the login code"*
- *"Where is user authentication handled?"*
- *"How does payment processing work?"*

Get precise answers with **file locations and line numbers in milliseconds**.

## ✨ Key Features

---

## 🛠️ Tech Stack

- **Backend:** FastAPI (Python) | **Database:** PostgreSQL
- **Vector DB:** Pinecone / Supabase pgvector | **Parser:** tree-sitter
- **Orchestration:** LangGraph | **Task Queue:** Celery + Redis
- **Frontend:** Next.js | **Styling:** Tailwind CSS | **Deployment:** Vercel

## 🎯 How It Works

1. **Connect GitHub** — One-click OAuth integration
2. **Index Code** — Automatic parsing with tree-sitter + embeddings
3. **Query** — Ask questions in natural language
4. **Get Results** — Instant answers with file locations & context
